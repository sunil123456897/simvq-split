# Эпистемический журнал Фазы K (`Calcite System-1`: Закон масштабирования `5M -> 25M -> 85M` и `Via Negativa` кэш-очистка)

## 1. Предрегистрация протокола (`Pre-Flight Calibration`)

- **Гипотеза №1 (`Via Negativa` по кэшу `System-1`):** в `simvq_split/` сохраняются микробуферы эпохи `1.5M` (`window_size=12` в коре, `W_chunks=5` в `VoronoiCrystalLayer`, `L_latch=7` в `NeuralWoodburyLayer`). Сокращение колец до `V1 (window_size=8, W_chunks=2, L_latch=3)` снижает строго $O(1)$ кэш на **`20.65%`–`25.56%`** (`S1_5M`: `123.61 -> 98.08 KB`; `S2_25M`: `278.01 -> 206.96 KB`; `S3_85M`: `590.36 -> 445.56 KB`) без деградации `OpenWeb BPB`, `S_5`, `Overwrite` и `Selective F1` сверх порога `2*sigma`.
- **Гипотеза №2 (Закон масштабирования чистого `System-1` `5M -> 25M -> 85M`):** при равном бюджете параметров (`< 1.0%` разброс) на едином чистом сыром UTF-8 корпусе (`0` арифметических трасс `SphericalALU`) `CalciteLeanSystem1LM` (`4.92M -> 23.54M -> 82.09M`) монотонно снижает `val_memmap_bpb` и `mean_openweb_bpb`, удерживает стабильную экстраполяцию контекста `4x` (`L=768 -> 2048`), обходит `RoPETransformerLM` и `ScaledHybridDeltaSWALM` на неабелевом счёте `S_5`, перезаписи `Overwrite OOD-Long` и отсеве ловушек `Selective F1`, а квантизационный зазор `2-bit uint8 LUT` закономерно сжимается с ростом ширины матриц (`d_model: 256 -> 448 -> 768`).
- **Порог Стоп-крана (`OEB <= 2`):**
  1. Gate 2 (`check_gate2_block_std_parity`): сдвиг `qat_mix=0` `< 1e-5`, отношение `std` по блокам строго в `[0.5, 1.5]`.
  2. Gate 3 (`Via Negativa` зонд `S1_5M`, `RTX 5060`): двойной базовый запуск `V0 (seed 2026, 2027)` задаёт `2*sigma`. Если `V1` уступает `V0` более чем на `max(2*sigma, min_floor)` по любому из `4` критериев (`mean_openweb_bpb`, `s5_sum`, `ov_ood_long`, `sel_f1_long`), попытка №2 проверяет промежуточный вариант `V1b (W=8, W_chunks=3, L_latch=4)`; при провале обоих фиксируется точная граница распада.
  3. Облачные ячейки (`Colab GPU`): возобновляемая запись каждой ячейки в `benchmarks/phase_k_cells/`. При двойном расхождении `BF16` или `4-Tap QAT` (NaN / деградация) на одном тире — немедленный Стоп-кран без третьей слепой попытки.

## 3. Итоги Фазы K и инженерные уроки для следующего масштабирования

1. **Что доказано на всех 3 масштабах (`5M -> 25M -> 85M`):**
   - **`2-bit uint8 LUT` без потерь на малой шкале (`85M`):** зазор `LUT - FP` по `val_memmap_bpb` падает в **`22.55x`** с ростом ширины `d_model` (`256: +0.1263` -> `448: +0.0627` -> **`768: +0.0056 BPB`**, на `OpenWeb` — **`+0.0017 BPB`**), а `2-bit LUT` на `85M` переигрывает свой `FP`-оригинал по `S_5` (`86.66%` vs `86.00%`), `Overwrite OOD-Long` (`40.67%` vs `38.00%`), `Trap Long` (`45.33%` vs `40.00%`) и `Selective F1` (`42.87%` vs `38.97%`).
   - **Чистый $O(1)$ кэш и `4x` экстраполяция:** схема `V1_lean_pruned (window_size=8, crystal_w_chunks=2, woodbury_latch_span=6)` даёт **`99.60 / 209.25 / 449.54 KB`** кэша на `L = 2048` (в **`123.37x / 171.28x / 164.01x`** меньше `RoPETransformerLM`, который на `4x` удлинении теряет `+0.7975 / +0.8559 BPB` и `+0.4199 BPB` хвоста), при `0.00%` разрывов UTF-8 и лучшем `5_CJK_UTF8` по всем тирам (`3.8621 -> 3.7870 -> 3.6755 BPB`).
   - **Условия сходимости без токенизатора:** (а) в `Stage 1A` держать `woodbury weight_decay = 0.0` при `0.05x LR`; (б) до замка `lock_router(True)` подавать на `SurpriseHNetChunker` **`100%` немаскированную прозу** с косинусным демпфированием LR роутера; (в) не сжимать `L_latch` ниже `6` чанков, иначе `16–17 B` фразы перезаписи выпадают из окна (`K10: L_latch = 3 -> OV = 0.0%`).
2. **Что пошло в честный отрицательный результат (`strict_fp_val_monotonic_passed = false`):**
   - Фиксированный языковой бюджет `Stage 2 = 800` шагов (`26.74M` байт OpenWeb) дал лишь **`0.326` байт/параметр** на `85M` (против `5.439` на `5M` и `1.136` на `25M`). Из-за недообучения по Чинчилле `mean_openweb_bpb` просел с `25M` к `85M` у всех трёх архитектур, а `Calcite FP val_bpb` поднялся с `2.1940` до `2.2481`.
   - При следующей итерации масштабирования `85M+` бюджет языкового `Stage 2` следует масштабировать пропорционально параметрам (`>= 10–20` байт/параметр) с сохранением когнитивного повтора в батче против вымывания `Overwrite`/`S_5` и пониженным `stage2_emb_lr <= 9e-4`.
